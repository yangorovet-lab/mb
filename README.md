# Морской бой

Браузерная игра «Морской бой», оптимизированная под мобильные устройства. Без сборки и зависимостей: обычный HTML, CSS и JavaScript. Работает офлайн как PWA.

## Запуск

Нужен любой статический сервер (для сервис-воркера и модулей файл должен открываться по `http://`):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/
```

Игра автоматически публикуется на GitHub Pages при каждом пуше (см. `.github/workflows/pages.yml`): https://yangorovet-lab.github.io/mb/

## Что внутри

- **Классика** — поле 10×10, флот 4‑3‑3‑2‑2‑2‑1‑1‑1‑1, корабли не касаются, после попадания ходишь снова.
- **Блиц** — 7 секунд на выстрел.
- **Арсенал** — радар (3×3, не тратит ход), бомба 3×3, торпеда по строке. Заряды за потопленные корабли.
- **Залп** — несколько снарядов за ход, размер залпа зависит от живых кораблей.
- **Вызов дня** — одна и та же скрытая доска для всех игроков (seed = дата), звёзды за число выстрелов, кнопка «Поделиться».
- **Дуэль** — двое на одном устройстве с экраном передачи хода.
- **Онлайн** — быстрый подбор случайного соперника или комната по коду из 5 символов и ссылке `?room=КОД`. Сервер хранит обе доски и сам считает выстрелы, так что смухлевать нельзя. 45 секунд на ход, три пропуска подряд — техпоражение. Переподключение: закрыл вкладку, открыл снова в течение полутора минут — партия продолжается. Реакции-эмодзи, реванш, раскрытие флота в конце.
- **Таблица лидеров вызова дня** — сервер сам строит доску по дате и повторяет выстрелы игрока, поэтому результат нельзя подделать.
- Три уровня ИИ: случайный, охотник с чётностью, вероятностная карта плотности.
- Удержание: опыт, уровни и звания, ежедневный бонус за серию входов, три миссии дня, 18 достижений, статистика, цветовые стили за уровни, сохранение и продолжение партии.
- Расстановка: перетаскивание, тап‑постановка, поворот тапом, случайная расстановка.
- Звук синтезируется через WebAudio, вибрация через Vibration API.

## Сервер

`server/` — Node.js 22 без фреймворков: HTTP-статика, WebSocket на `/ws`, SQLite через встроенный `node:sqlite`. Зависимость одна — `ws`.

```bash
cd server && npm install
npm start            # http://localhost:8080, данные в server/data/
npm test             # тесты правил комнат и проверки вызова дня
```

Эндпоинты: `GET /healthz`, `GET /api/stats`, `GET /api/daily/top?date=YYYY-MM-DD&pid=…`.

Клиент подключается к серверу того же хоста. Если статика лежит отдельно (например, на GitHub Pages), адрес сервера задаётся в `js/config.js` или через переменную репозитория `SERVER_URL`, которую подставляет workflow Pages.

## Деплой на VPS

Одна команда на чистом Ubuntu/Debian (Docker + Caddy с автоматическим HTTPS):

```bash
curl -fsSL https://raw.githubusercontent.com/yangorovet-lab/mb/claude/epic-lovelace-vua5k7/deploy/install.sh | sudo bash -s -- игра.example.com
```

Без домена скрипт возьмёт `<IP>.sslip.io` и тоже получит сертификат. Повторный запуск обновляет код и перезапускает контейнеры.

Автодеплой по пушу: workflow `.github/workflows/deploy-vps.yml` заходит на сервер по SSH. Нужны секреты репозитория `VPS_HOST`, `VPS_USER`, `VPS_SSH_KEY` (опционально `VPS_PORT`) и переменная `DOMAIN`.

Полезное на сервере:

```bash
cd /opt/battleship
docker compose logs -f app        # логи игры
docker compose ps                 # состояние
docker compose exec app sh -c 'ls -la /data'   # база SQLite
```

## Структура

```
index.html            разметка экранов
css/style.css         стили, темы, анимации
js/util.js            DOM-хелперы, seeded RNG, утилиты
js/engine.js          доска, флот, правила, способности, режимы
js/ai.js              противник (3 уровня), залп и способности ИИ
js/progress.js        профиль, опыт, миссии, достижения, настройки, сохранение
js/audio.js           синтез звуков
js/config.js          адрес игрового сервера
js/net.js             WebSocket-клиент с автопереподключением
server/index.js       HTTP + WebSocket, маршрутизация сообщений
server/rooms.js       комнаты, матчмейкинг, таймер хода, реконнект
server/daily.js       проверка результатов вызова дня
server/db.js          SQLite
Dockerfile, docker-compose.yml, deploy/   контейнеры, Caddy, установка на VPS
js/app.js             экраны, расстановка, бой, итоги
sw.js                 офлайн-кэш
manifest.webmanifest  PWA-манифест
icons/                иконки
```

Прогресс игрока хранится в `localStorage`; сервер нужен только для онлайн-партий и таблицы дня, всё остальное работает офлайн.
