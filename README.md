# Морской бой

Браузерная игра «Морской бой», оптимизированная под мобильные устройства. Без сборки и зависимостей: обычный HTML, CSS и JavaScript. Работает офлайн как PWA.

## Запуск

Нужен любой статический сервер (для сервис-воркера и модулей файл должен открываться по `http://`):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/
```

Игра автоматически публикуется на GitHub Pages при каждом пуше (см. `.github/workflows/pages.yml`): https://yangorovet-lab.github.io/mb/

## Что внутри

- **Классика** — поле 10×10, флот 4‑3‑3‑2‑2‑2‑1‑1‑1‑1, корабли не касаются, после попадания ходишь снова.
- **Блиц** — 7 секунд на выстрел.
- **Арсенал** — радар (3×3, не тратит ход), бомба 3×3, торпеда по строке. Заряды за потопленные корабли.
- **Залп** — несколько снарядов за ход, размер залпа зависит от живых кораблей.
- **Вызов дня** — одна и та же скрытая доска для всех игроков (seed = дата), звёзды за число выстрелов, кнопка «Поделиться».
- **Дуэль** — двое на одном устройстве с экраном передачи хода.
- Три уровня ИИ: случайный, охотник с чётностью, вероятностная карта плотности.
- Удержание: опыт, уровни и звания, ежедневный бонус за серию входов, три миссии дня, 18 достижений, статистика, цветовые стили за уровни, сохранение и продолжение партии.
- Расстановка: перетаскивание, тап‑постановка, поворот тапом, случайная расстановка.
- Звук синтезируется через WebAudio, вибрация через Vibration API.

## Структура

```
index.html            разметка экранов
css/style.css         стили, темы, анимации
js/util.js            DOM-хелперы, seeded RNG, утилиты
js/engine.js          доска, флот, правила, способности, режимы
js/ai.js              противник (3 уровня), залп и способности ИИ
js/progress.js        профиль, опыт, миссии, достижения, настройки, сохранение
js/audio.js           синтез звуков
js/app.js             экраны, расстановка, бой, итоги
sw.js                 офлайн-кэш
manifest.webmanifest  PWA-манифест
icons/                иконки
```

Прогресс хранится в `localStorage`, серверная часть не нужна.
